# Consumer Price Index & Inflation Analysis

## 📊 Project Overview

An Excel-based analysis of Consumer Price Index (CPI) and inflation data across Indian states, sectors, and commodity groups. The project focuses on identifying inflation trends, regional variations, and differences across commodity categories.

## 🎯 Objective

- Analyze CPI and inflation trends over time
- Compare inflation across Indian states
- Examine CPI across commodity groups
- Compare inflation across sectors
- Identify states and commodity groups with notable inflation levels
- Present findings through an interactive Excel dashboard

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- PivotTables & PivotCharts
- Excel formulas and conditional calculations
- Slicers
- KPI Cards
- Data Visualization
- Trend Analysis
- Business/Economic Interpretation

## 📁 Dataset

The dataset contains approximately 175,000 records with fields including:

- Date
- State Name
- State Code
- Commodity Group
- Sector
- Consumer Price Index
- Inflation

## 📈 Dashboard

The dashboard includes:

- Average Inflation KPI
- Average CPI KPI
- Highest and Lowest Inflation State indicators
- Inflation Trend Over Years
- State-wise CPI visualization
- Sector-wise Inflation
- Commodity Group-wise CPI
- Commodity Group-wise Inflation
- Interactive filters for Year, State, Sector, and Commodity Group

## 🔍 Key Analysis Areas

### Inflation Trends
Examined changes in inflation across different years to identify periods of increasing or decreasing price pressure.

### State-wise Analysis
Compared CPI and inflation across Indian states to identify regional differences.

### Commodity Analysis
Analyzed commodity groups to understand which categories show higher CPI and inflation levels.

### Sector Analysis
Compared inflation across Combined, Rural, and Urban sectors.

## 💡 Key Insights

The dashboard allows users to identify:

- Differences in inflation across Indian states
- Changes in inflation over time
- Commodity groups associated with higher inflation
- Differences between rural, urban, and combined sectors
